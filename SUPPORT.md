# Support

## Where to get help

- **Installation, configuration, and end-user support:** [WordPress.org support forum](https://wordpress.org/support/plugin/mikesoft-teamvault/).
- **Questions and workflows:** GitHub Discussions on this repository.
- **Defects in this repository's source or documentation:** GitHub Issues using the bug report form.
- **Security problems:** see [`SECURITY.md`](SECURITY.md), never a public issue.
- **Distribution-specific problems** (plugin directory listing, package download, WordPress.org hosting): use the WordPress.org support channel.

## Before asking

1. Check the README troubleshooting section.
2. Search the support forum, existing issues, and discussions.
3. Reproduce on the latest release published on WordPress.org with a clean configuration.

## What support covers

This is a free, maintainer-run plugin. Support covers defects in the latest release and questions about documented behavior. It does not cover customized deployments, third-party themes or plugins, hosting configuration, or consulting work.

## Response expectations

Best effort, usually within a week. Reports without a version and a reproduction may be closed with a request for details.
